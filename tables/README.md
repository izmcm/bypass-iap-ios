# Tables

This repository contains the tables and corresponding PDF files used in our study on vulnerability analysis of iOS apps.

## Contents

* **app_specific_table.tex**
  LaTeX source for the table containing results from the *app-specific analysis*.

* **app_specific_table.pdf**
  Compiled PDF version of the app-specific analysis table.

* **app_agnostic_table.tex**
  LaTeX source for the table containing results from the *app-agnostic analysis*.

* **app_agnostic_table.pdf**
  Compiled PDF version of the app-agnostic analysis table.

## Description

* **App-Specific Analysis**
  Evaluates vulnerabilities within individual apps, focusing on issues such as:

  * Unprotected code
  * Insecure storage
  * Missing receipt validation

* **App-Agnostic Analysis**
  Compares apps across different timeframes (2022/2023 vs. 2025) to assess:

  * Persistence of vulnerabilities
  * Evolution of security practices over time

## Usage in Paper

These tables correspond to the results presented in our study and can be referenced as supplementary material.

## Notes

* The data reflects the versions of apps analyzed at the time of the study.
* Some apps may no longer be available on the App Store or may have changed since analysis.
